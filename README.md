## FAQ

### Is GPORTAL's $6.14 a monthly price?

No. It is a 3-day starting price. The 10-slot plan costs **$15.35 per 30 days** or **$41.44 per 90 days**. The 20-slot plan costs **$60.87 per 90 days**. The 90-day 10-slot rate converts to about $13.81/mo, but that is a conversion from a prepaid period.

### Can I run ARK: Survival Ascended on a cheap ASE plan?

Not if the host says it is ASE only. GPORTAL explicitly states that its ARK: Survival Evolved servers are not compatible with ASA. Sparked Host and Servers4Gamers list ASE. Hostinger claims either version can be installed. Confirm the version before paying.

### Why is a $24 VPS more expensive than an $8 managed server?

The $8 Sparked Host Thatch is a managed ARK server. Gravel Host's $24 Tier 1 is a 16 GB ASA VPS, and Gravel states that it is infrastructure only. You install and operate ARK, and you handle the licence. The invoice is higher and the labour is yours.

### Do refunds cover VPS plans?

Sparked Host refunds ARK game hosting within 48 hours but excludes VPS and dedicated servers. Gravel Host offers a 72-hour first-purchase refund, one per account, with processing fees deducted and renewals and add-ons excluded. Hostinger says cancel anytime but does not state a refund window in the reviewed page.

### How do I move an existing ASE save?

GPORTAL requires a 10-slot server to upload an official ASE save. Sparked Host supports SFTP or backup upload and an Importer tab. Servers4Gamers describes copying the `SavedArk` folder. Hostinger says to download the backup first, then buy a Game Panel plan. Confirm the destination's slot and version requirements first.

### Does SpinServers sell ARK hosting?
